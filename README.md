# 📊 Econopulse

Платформа для комплексного анализа макроэкономических показателей с агрегацией данных из множества источников.

## 📝 Описание проекта

Econopulse — это мощный аналитический инструмент, который предоставляет специалистам, инвесторам и исследователям доступ к актуальным макроэкономическим данным. Платформа объединяет информацию из различных источников, предлагая продвинутую визуализацию и инструменты для глубокого анализа экономических тенденций.

## 🛠 Технологический стек

### 🎨 Frontend
- **⚛️ React ** + **🔷 TypeScrip** - библиотека для построения пользовательских интерфейсов 
- **🎨 Mantine UI** - современная библиотека компонентов
- **📊 Chart.js** - продвинутая визуализация данных


### 🚀 Backend
- **🖥️ Express.js** + **🔷 TypeScript** - высокопроизводительный серверный фреймворк
- **🗄️ Prisma** - современный ORM для работы с базой данных
- **📝PostgreSql** - база данных
